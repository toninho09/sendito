Send an HTTP request and read the response.

── Steps ──
  1.  Press {key:new_request}. A new tab opens with the focus on the URL.
  2.  Type the URL, for example https://httpbin.org/get.
  3.  To change the method, move the focus to the method (GET) with {key:focus_prev}. Press Enter, choose the method and press Enter. You can also type the first letter of the method.
  4.  To add a query parameter, click the Params tab (or move the focus to the request tabs and press Enter). Type the name, press {key:table:next_cell}, type the value. The empty row at the bottom adds a new row.
  5.  To add a header, open the Headers tab ({key:next_subtab} opens the next tab) and add a row in the same way.
  6.  To send JSON, open the Body tab and choose JSON with Left or Right. Type the JSON. {key:format_body} formats it. The bottom border shows "✓ JSON" or the line of the error.
  7.  Press {key:send} to send the request. Enter in the URL also sends it.
  8.  Read the response pane: Body, Headers, Timing and Results. Press {key:focus_down} to go to it.

Result: the response pane shows the status, the time, the size and the body.

── Good to know ──
  •  {key:table:toggle_row} turns a table row off without deleting it. {key:table:delete_row} deletes it.
  •  {key:cancel} stops a request that takes too long.
  •  The tab is not saved yet. See "Save and organize".
