Keep tokens and passwords out of the files that you share, and add
authentication to a request.

── Make a secret variable ──
  1.  Press {key:manage_envs} to open the environment editor.
  2.  Add a variable, for example token.
  3.  Move to the Type cell and press Space until it shows secret (in .sendito/secrets.toml) or keychain (in the keychain of the system).
  4.  Type the value and press {key:dialog:dialog_confirm} to save.
The screen and the history show •••••• for a secret.

── Move a typed value to a secret ──
  1.  When a credential field has a plain value, it shows "⚠ plain text".
  2.  Put the focus on that field and press {key:move_to_secret}.
  3.  Type a name for the secret. Sendito keeps the value in .sendito/secrets.toml and writes {{name}} in the field.

── Add authentication ──
  1.  Open the Auth tab of the request.
  2.  Choose the type: Inherit, No auth, Basic, Bearer token, API key, OAuth 2, Digest, AWS Signature v4 or JWT.
  3.  Fill the fields with variables, for example {{token}} for a Bearer token.
  4.  Press {key:send}.

── Auth for a full folder ──
  1.  Select the folder in the tree and press {key:tree_folder_settings}.
  2.  Open the Auth tab and set the auth.
  3.  The requests in the folder with the type Inherit use it.

── Good to know ──
  •  OAuth 2 uses an identity. The command :oauth edits the identities, and :auth login signs in.
  •  {key:reveal_secrets} shows or hides the credentials typed as plain text.
