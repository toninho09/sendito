Call a tool, read a resource or get a prompt from an MCP server.

── Add a server ──
  1.  Open the command palette ({key:palette}), type :mcpadd and a name for the server, and press Enter.
  2.  Type the URL (kind http) or the command line (kind stdio) of the server.
  3.  Press Enter to save. {key:manage_mcp_servers} opens the server editor when you want to change it.

── Call a tool ──
  1.  Press {key:new_mcp_request}. An MCP tab opens.
  2.  Type the server name, or an http:// or https:// URL.
  3.  Move the focus to the tool and press Enter. Choose the tool from the list.
  4.  Open the Args tab and write the arguments as JSON. {key:complete} shows the arguments of the tool.
  5.  Press {key:send}.

Result: the Body tab shows the result of the tool. The Request tab shows the
message that Sendito sent.

── Good to know ──
  •  In the Tool tab, the operation can be a tool, a resource or a prompt.
  •  The command :mcptools loads the tool list again.
  •  The command :auth login <server> signs in to a server that needs OAuth.
